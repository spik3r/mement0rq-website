A QUICK START

One schema. Two directions.

Load the example to try both directions. Every editor supports ordinary copy and paste. Nothing is uploaded or saved between visits.

01 / Define

Paste a .proto definition or import multiple files. All imported definitions are parsed together. Select a message from the dropdown.

02 / Convert

Paste JSON and choose Encode, or paste bytes and choose Decode. Switching Base64 / Hex converts the current payload.

03 / Take it with you

Copy or download any editor. Generated schemas are drafts: JSON cannot recover original field numbers, bytes, maps, or enum types.

Format notes & limitations

Proto2 and proto3 schemas are supported by the bundled protobuf.js library. Field names retain their schema spelling. Decoding requires the correct schema and message type; unknown fields are discarded and a wrong schema can still produce plausible output. Paste raw protobuf, not a gRPC frame. Imports must be provided locally, including any well-known types. Inputs are limited to 2 MiB of text per editor/file. No network imports, automatic credential checks, or payload execution.
